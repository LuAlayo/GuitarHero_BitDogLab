# GuitarHero_BitDogLab

![Guitar Hero setup](imagens/image.jpg)

Adaptação do jogo Guitar Hero para a placa BitDogLab V7 (RP2040), em MicroPython. Usa o display OLED para mostrar as notas descendo pela pista e os botões A, B e C como as "cordas" da guitarra. Projeto da disciplina EA801 - Laboratório de Projeto de Sistemas Embarcados (FEEC/Unicamp).
